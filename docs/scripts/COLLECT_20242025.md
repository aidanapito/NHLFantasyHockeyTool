# Collecting 2024-2025 Season Data

## ✅ Data Availability Confirmed

The NHL API has data for the 2024-2025 season! A test with Connor McDavid successfully found 67 game logs.

## Quick Start

### Test First (Recommended)
```bash
# Test with 10 players
npm run collect-game-logs -- --season=20242025 --limit=10
```

### Full Collection
```bash
# Collect all players (15-30 minutes)
npm run collect-game-logs -- --season=20242025
```

## After Collection

Once collection is complete, add the season to the training config:

**File**: `analytics-service/modeling/config.py`

Add `"20242025"` to the seasons list:
```python
seasons: List[str] = field(
    default_factory=lambda: [
        "20212022",
        "20222023",
        "20232024",
        "20242025",  # Add this
        "20252026",
    ]
)
```

This will give you **5 seasons** of training data (~220,000+ games total).
